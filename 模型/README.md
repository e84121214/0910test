# 模型目錄

| 資料夾 | 用途 | 訓練入口 |
|---|---|---|
| `01_衛星模型` | 16 波段、6 波段差、時間與地理特徵 | `train_gru.py` |
| `02_地面氣象模型` | 10 公里鄰站地面氣象、時間與地理特徵 | `train_ground_gru.py` |
| `03_衛星加地面模型` | 衛星波段、波段差及地面氣象的混合輸入 | `train_combined_gru.py` |
| `歷史實驗` | 舊版多特徵比較、單站回歸及探索工具 | 僅供追溯 |

每個現行模型資料夾均包含資料序列程式、訓練程式、實驗 README 與自己的 `results`。三種模型各自保留獨立訓練入口與輸出，不直接覆寫其他模型。

所有模型共同從專案根目錄的 `來源資料` 讀取輸入資料。
