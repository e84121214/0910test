# 來源資料

現行模型使用下列資料：

- `visibility_satellite_2023_btd.parquet`：衛星模型的 16 波段與 6 波段差，也是地面模型的標籤、測站與共同樣本來源。
- `第一階段可交付成果_2023_地面氣象資料from柯/資料/氣象逐時_2023.parquet`：逐時地面氣象觀測。
- 同一交付包中的 `10公里氣象站配對.csv` 與 `氣象測站品質.csv`：鄰站關係及品質篩選。

`visibility_satellite_2023_clean.parquet` 保留供歷史實驗使用。`亮溫差資料建立` 和地面氣象交付包保留原始說明、處理程式及交付內容，方便追溯資料產生流程；其中可能包含和根目錄 canonical 檔案相同的副本。

Parquet 檔案已由 `.gitignore` 排除，不會因目錄整理而被加入 Git。
