## 概述

本資料集用於研究 **衛星多光譜波段與地面能見度（霧）的關係**，目標是利用向日葵衛星（Himawari）AHI 感測器 16 個波段的觀測值，預測地面能見度或判斷是否起霧。

> 2023 年資料期間，運作中的為 Himawari-9（2022/12/13 起接替 Himawari-8）。
> 兩者搭載相同的 AHI 感測器，16 波段規格一致。

- **檔案**: `visibility_satellite_2023_clean.parquet`
- **格式**: Apache Parquet（zstd 壓縮），建議使用 Polars 讀取
- **大小**: ~82 MB（Parquet）；若轉 CSV 約 1.5-2 GB
- **筆數**: 2,546,998 筆
- **測站數**: 78 站
- **時間範圍**: 2023-01-01 ~ 2023-12-31（UTC+0）
- **時間解析度**: 10 分鐘（與衛星觀測頻率對齊）

## 研究任務

每一筆資料代表「**某測站在某一時刻**」的衛星觀測與地面能見度配對。核心邏輯：

```
輸入 (X)：同一時刻的衛星 16 波段值（B01~B16）
         可加入輔助特徵：座標、海拔、時間、衍生指標等
目標 (y)：該時刻該測站的地面能見度
```

兩種建模方向：

| 任務 | 目標欄位 | 說明 |
|------|----------|------|
| **分類** | `is_fog` | 二元分類（能見度 < 1km → 1，否則 0） |
| **回歸** | `Visibility_km` | 預測連續能見度值（公里） |

注意：本資料集**不含時序資訊**，每筆獨立，不依賴前後時刻。純粹是「衛星看到的 → 地面實際能見度」的空間對應關係。

## 使用注意事項

### 1. 能見度儀量測上限不一致

不同測站的能見度儀有不同的量測上限：

| 上限 | 說明 | 影響站 |
|------|------|--------|
| 7.5 km | 高公局部分舊型儀器 | CAA02, CAA06, CAB04, CAC01, CAD01, CAD09, CAE04, CAE08, CAG03, CAG05, CAJ01, CAL02, CAL08, CAN02, CAN09, CAP04, CAP06 |
| 20 km | 高公局部分站 | CAC06, CAD10, CAE10, CAG07, CAG08, CAJ03, CAL09, CAN11 |
| 40~50 km | 高公局較新儀器 | 其餘 Road 站 |
| 75 km | 氣象署 ACOS | 所有 ACOS 站（C 開頭） |

**影響**：做回歸模型時，7.5 km 上限的站在高能見度時會被截斷（ceiling effect），模型可能學到錯誤的天花板。建議處理方式：
- 分類模型（霧/非霧）：影響較小，因為關注的是低能見度端
- 回歸模型：考慮只使用上限 ≥ 40 km 的站，或將能見度截斷在統一上限

### 2. 可見光波段夜間為零

B01~B06 為可見光/近紅外波段，**夜間無太陽反射，值為 0**。這不是缺值，是物理特性。建議：
- 加入日夜判斷特徵（可用太陽高度角或簡單時間切分）
- 或在模型中加入時間特徵讓模型自己學

### 3. 部分測站冬季資料偏少

以下測站在部分月份資料覆蓋率明顯偏低（< 50%）：

| 測站 | 問題月份 | 說明 |
|------|----------|------|
| CAE11 | 1~3月 | 覆蓋率僅 20-24%，可能儀器故障 |
| CAJ03 | 1, 3, 10月 | 覆蓋率 15-36% |
| CAG09 | 1, 3~4, 10, 12月 | 覆蓋率 21-53% |
| CAC02 | 全年偏低 | 多數月份 42-58% |
| CAN12 | 1, 4, 7月 | 覆蓋率 47-56% |

做 Leave-One-Month-Out 交叉驗證時，這些站在低覆蓋月份可能造成 bias。

### 4. 霧事件極度不平衡

全資料集中 `is_fog == 1` 僅佔 **0.63%**（16,072 / 2,546,998）。訓練分類模型時務必處理不平衡問題（如 SMOTE、class weight、focal loss 等）。

### 5. 已移除的測站

- **CAB05**：全年僅 1 筆有效資料，已從資料集移除。

## 先前研究成果與建議特徵

以下是我們嘗試過的特徵工程與模型實驗結果，供後續研究參考。**這些衍生特徵不包含在資料集中**，需自行計算（範例見 `example_usage.py`）。

### 建議衍生特徵

#### A. 衛星衍生特徵（經 KS 檢定驗證，霧/非霧有顯著分離度）

| 特徵 | 計算方式 | 物理意義 | KS 統計量 |
|------|----------|----------|-----------|
| `BTD_B14_B15` | B14 - B15 | **Split Window Difference**：霧/低雲的微物理特性會讓 11μm 與 12μm 亮溫差異變大。文獻中最常用的霧偵測指標之一 | 0.401 |
| `BTD_B13_B15` | B13 - B15 | 紅外窗區差異，與 BTD_B14_B15 互補 | — |
| `B04_B02_ratio` | B04 / (B02 + 1.0) | **近紅外/可見光比值**：霧層會改變可見光與近紅外的散射比例（僅白天有效） | 0.310 |
| `WV_diff_B08_B10` | B08 - B10 | **水氣通道差（上層-下層）**：反映大氣中水氣垂直分布，間接指示近地面水氣凝結條件 | >0.25 |
| `WV_diff_B09_B10` | B09 - B10 | 水氣通道差（中層-下層），同上 | >0.25 |
| `B03_B04_ratio` | B03 / B04 | 可見光紅/近紅外比，與霧的光學特性相關 | — |

> **KS > 0.25** 表示該特徵在「有霧」vs「無霧」樣本中的分布有明顯差異，值越大分離度越好。

#### B. 時間特徵

| 特徵 | 計算方式 | 說明 |
|------|----------|------|
| `hour_sin / hour_cos` | sin(hour×2π/24), cos(hour×2π/24) | 日週期編碼（輻射霧多在清晨，平流霧無明顯日週期） |
| `month_sin / month_cos` | sin(month×2π/12), cos(month×2π/12) | 季節週期（台灣霧季主要在秋冬） |
| `solar_elevation` | Spencer (1971) 簡化天文公式 | 太陽高度角（度），負值=夜間。比固定時間切分更準確 |
| `is_night` | solar_elevation < 0 → 1 | 日夜二元標記，配合可見光波段使用 |

#### C. 地理特徵

| 特徵 | 計算方式 | 說明 |
|------|----------|------|
| `dist_to_coast_km` | 測站到 Natural Earth 10m 海岸線最短距離 | 平流霧（海霧）多發生在沿海，距海距離是重要判別因子 |
| `Elevation_m` | 資料集已含 | **模型中最重要的特徵**（見下方 feature importance），海拔決定霧型態 |
| `Latitude / Longitude` | 資料集已含 | 地理位置，模型重要性排名第 2-3 |

### 模型實驗結果

#### Feature Importance（LightGBM，gain 排序）

模型訓練後的特徵重要性排名：

| 排名 | 特徵 | Gain | 說明 |
|------|------|------|------|
| 1 | **Elevation_m** | 240,802,474 | 海拔是霧型態的最強指標 |
| 2 | **Longitude** | 28,095,503 | 經度（東西岸差異） |
| 3 | **Latitude** | 23,917,727 | 緯度（南北差異） |
| 4 | **B10** | 6,955,505 | 水氣下層（7.3μm） |
| 5 | **B11** | 6,920,327 | 雲相態（8.6μm） |
| 6 | **B07** | 6,122,848 | 中紅外（3.9μm） |
| 7 | **B08** | 5,367,093 | 水氣上層（6.2μm） |
| 8 | **B12** | 4,560,236 | 臭氧（9.6μm） |
| 9 | **BTD** | 3,095,805 | 亮溫差 |
| 10 | **B09** | 3,002,198 | 水氣中層（6.9μm） |

> 地理/地形特徵（海拔、經緯度）佔了前三名，衛星波段中以**熱紅外與水氣通道**（B07-B12）最重要，可見光波段（B01-B04）排名較低。

#### 分組訓練策略

我們嘗試過依霧的物理成因將測站分三組獨立訓練：

| 組別 | 條件 | 霧型態 | 結果 |
|------|------|--------|------|
| **Mountain** | Elevation > 500m | 地形霧/雲霧（orographic） | AUC ~0.87-0.94，表現最好 |
| **Plain** | Elevation ≤ 500m 且本島 | 輻射霧（radiation） | AUC ~0.66-0.89，FAR 極高 |
| **Offshore** | Region == 'Offshore' | 平流霧/海霧（advection） | AUC ~0.75-0.94，樣本少 |

**Mountain 組效果最好**，因為地形霧的衛星信號最明確。**Plain 組最難**，因為輻射霧薄且發展快，衛星解析度不足以捕捉。

#### 加入新特徵 vs 基線比較

在相同 LOMOCV 設定下，加入衍生特徵（BTD_B14_B15、水氣差、太陽角等）後：

- Mountain 組：AUC 提升約 0.01-0.02，CSI 提升明顯
- Plain 組：改善不大，FAR 仍然很高
- Offshore 組：有少量改善，但樣本太少不穩定

#### 驗證策略建議

- **LOMOCV（Leave-One-Month-Out）**：每次留 1 個月當測試集，其餘 11 個月訓練。比隨機 split 更能反映真實預測情境（時間外推）
- **注意**：霧事件僅佔 0.63%，評估時 Accuracy 無意義，應關注 **AUC、POD（偵測率）、FAR（虛報率）、CSI（臨界成功指數）**


## 資料產生流程（供追溯）

```
原始 CSV (高公局1分鐘 + 氣象署ACOS)
  → process_visibility.py         合併 + 轉 UTC+0
  → downsample_visibility.py      1分鐘 → 10分鐘平均
  → data_processor.py             擷取衛星 H5 像素值
  → run_all_months.py             批次處理 12 個月
  → create_optimized_dataset.py   join_asof 合併（容差 5 分鐘）
  → add_region_labels.py          加入地理分區
  → add_features.py               加入衍生特徵
  → [本資料集]                     精簡為核心欄位
```

所有處理腳本位於 `AI/` 目錄下。
